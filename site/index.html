Check a repository

Paste a public GitHub link. vetcode reads it on a throwaway GitHub runner, never running it, and tells you what the code can do and whether anything looks like malware.

Checks run on openyard.cloud, the community site vetcode comes from. Results are public, like the repositories. Patterns, not proof: read the code before you trust it.

Four moments it steps in

In Claude Code the guard runs on its own, as a hook. Other agents call the same checks as a tool, or load the review procedure as a skill.

Packages

Before install

npm, pnpm, yarn, bun, pip, uv, cargo and go. A name that does not exist, a look-alike of a popular one, a malware advisory, malicious code in the archive (downloaded and read, never run), a release only hours old. Allow, ask or deny, before the command runs.

Repositories

After clone

Before the agent builds or runs anything: install scripts that decode and run code, instructions planted in agent files such as CLAUDE.md, hooks and auto-approved MCP servers in project settings.

MCP servers

Before it's added

Added with claude mcp add or written into a config file: the package the server would start, and an address behind a tunnel or on plain HTTP.

A review

When you ask

"Is this repo safe to run?" or "review this before I deploy": a scan for malware, supply-chain tricks, leaked keys and risky CI and server config, and a procedure that has the agent confirm each finding by reading the code.

Web bugs

It lists the dangerous calls in web code as places to read. They stand at about one real injection bug in ten.

Logic bugs

It does not make your agent better at finding missing authorization or business-logic flaws.

No guarantee

New malware can still slip through. A clean report means nothing obvious was found.

Install

Node.js 18 or newer, nothing else. vetcode is not on npm: every command runs it from the repository, pinned to a release.

The plugin: the guard on every install, clone and MCP server, plus the review skill.

claude plugin marketplace add openyard-cloud/vetcode && claude plugin install vetcode@openyard

Codex, Gemini CLI, GitHub Copilot, Cursor, Amp, Goose, opencode and any agent that loads Agent Skills.

npx skills add openyard-cloud/vetcode

For any client that speaks MCP. In Claude Desktop, open vetcode.mcpb from the latest release instead. Listed in the MCP Registry as io.github.openyard-cloud/vetcode.
